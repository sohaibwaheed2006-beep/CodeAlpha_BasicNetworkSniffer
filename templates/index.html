📖 Network Protocol Reference Guide

Learn how data flows through the OSI model and understand the protocols captured above.

The OSI Model — 7 Layers of Networking

7ApplicationHTTP, DNS, FTP, SSH, SMTP — User-facing protocols
6PresentationTLS/SSL encryption, data encoding, compression
5SessionNetBIOS, RPC — Session establishment & teardown

Key Protocols Explained

HTTP / HTTPS Layer 7 · Port 80 / 443

HyperText Transfer Protocol — the foundation of web communication. Every time you visit a website your browser sends an HTTP GET request. The server responds with a status code (200 OK, 404 Not Found) and the page content.

GET /index.html HTTP/1.1 Host: www.example.com User-Agent: Mozilla/5.0 Accept: text/html ← HTTP/1.1 200 OK Content-Type: text/html Content-Length: 1256
DNS Layer 7 · UDP Port 53

Domain Name System — the internet's phone book. It translates human-readable names like google.com into IP addresses (142.250.80.46). DNS queries are typically sent over UDP for speed.

Query: google.com (A record) → 8.8.8.8 (Google DNS) Response: 142.250.80.46 TTL=300s Type A → IPv4 address Type AAAA→ IPv6 address Type MX → Mail server
TCP Layer 4 · Connection-Oriented

Transmission Control Protocol — guarantees reliable, ordered delivery. Uses a 3-way handshake before data flows: SYN → SYN-ACK → ACK. TCP flags indicate state: SYN=connect, FIN=close, RST=reset, PSH=push data.

Client → SYN (seq=1000) Server → SYN+ACK (seq=5000, ack=1001) Client → ACK (ack=5001) [Connection established] Client → PSH+ACK (data) Server → FIN+ACK (close)
UDP Layer 4 · Connectionless

User Datagram Protocol — fast but unreliable. No handshake, no acknowledgement, no guaranteed order. Used where speed matters more than reliability: DNS, video streaming, online gaming, VoIP.

Client → Datagram (no handshake) Server → Datagram (may arrive out of order) No retransmission on loss. Applications handle reliability themselves. Use cases: DNS, NTP, DHCP, VoIP, Video
ICMP Layer 3 · Network Diagnostics

Internet Control Message Protocol — used by network devices to send error messages and operational information. The ping command sends ICMP Echo Request (type 8) and expects Echo Reply (type 0). traceroute exploits TTL and ICMP Time Exceeded.

ping google.com ICMP Type 8 → Echo Request ICMP Type 0 ← Echo Reply ICMP Type 11 → Time Exceeded (traceroute) ICMP Type 3 → Destination Unreachable
ARP Layer 2 · Address Resolution

Address Resolution Protocol — maps IP addresses to MAC addresses on a local network. Before sending data, your computer broadcasts "Who has IP 192.168.1.1? Tell me your MAC address." ARP poisoning is a classic MITM attack vector.

Broadcast → Who has 192.168.1.1? (ff:ff:ff:ff:ff:ff) Reply ← 192.168.1.1 is at aa:bb:cc:dd:ee:ff Stored in ARP cache for 60-120 seconds.
